7. 测验（10 题，通过标准 ≥80%）

Q1（选择）scope 门禁为何要加 "." 边界？A. 性能 B. 防 notevil.com 绕过 evil.com 匹配 C. 美观 D. 兼容 IPv6
Q2（判断）MCP stdio connect 失败会泄漏子进程。→ 修复前是（无回滚），修复后 try/except + disconnect 回滚
Q3（简答）事件广播为何用 run_coroutine_threadsafe 而非 create_task？publish 在引擎线程执行，get_running_loop 可能拿到引擎自己的 loop；在其上 create_task 会从非归属线程调 ws.send（协议对象非线程安全，帧交错）。必须 threadsafe 调度回 WS 服务 loop
Q4（判断）插件目录加入 sys.path 是安全的。→ 错（插件内 json.py/logging.py 可劫持宿主 import），须 spec_from_file_location 隔离
Q5（选择）压测 200 并发的 P95 延迟？A. 9.7ms B. 10.5ms C. 11.6ms D. 50ms
Q6（简答）CLI 双入口铁律是哪三处？Typer(entrypoint.py) + argparse(main.py) + 处理器(cmd_xxx)，加参数必须三处同步
Q7（判断）全量快检 17 个失败是本次改动造成的。→ 错（多轮基线 stash 对照定性：Windows 缺 bash/echo 12 + 缺 redis 5）
Q8（选择）桌面端 Web UI 由谁托管？A. Electron 内置服务器 B. Python Host 同端口托管（壳只 loadURL） C. 第三方 CDN D. file:// 直读
Q9（简答）发布新版本要上传哪 4 个文件到更新源？Setup exe + Portable exe + latest.yml（必须，electron-updater 元数据）+ blockmap
