# ADR-0016：挂机自主决策引擎 + 权限全中文表达

- **状态**：已接受（2026-10-29）
- **用户诉求**：① 权限相关概念要用**中文命名并解释清楚**；② 要能**挂机让 Agent 自己决策把任务跑完**

## 一、权限全中文表达（不需要懂英文枚举）

原先对外暴露的是 `plan / default / auto-edit / yolo`、`allow / deny / ask`、
`allow / prompt / forbidden` —— 用户得先翻译一遍才知道会发生什么。

现在每层都有中文名 + 行为解释 + 风险提示：

| 层 | 中文名示例 | 行为解释 |
|:---|:---|:---|
| 审批模式 `ApprovalMode` | 计划模式（只读） / 默认模式（改前确认） / 自动编辑模式（改文件不问，跑命令问） / 全自动模式（都不问） | 每个模式都写明"读/写/执行分别会怎样" + 风险 |
| 权限结论 `Effect` | **放行 / 拒绝 / 需确认** | — |
| 命令策略结论 `Decision` | **允许执行 / 需审批 / 禁止执行** | 拒绝文案带理由（Codex 风格） |
| 挂机级别 `AutonomyLevel` | **有人盯 / 半挂机 / 全挂机** | 见下 |

新增命令 **`clawd permissions [--rules]`**：一屏中文讲清四层概念、受保护路径、全部内置命令规则。

## 二、挂了机让 Agent 自己跑完：难在哪

真正的难点不是"放行一切"，而是**没人在的时候怎么决策才不闯祸**：

1. 遇到需要审批的操作——没人能批，**既不能默认放行，也不能卡死**
2. 必须**该停就停**（预算烧完、连续失败、反复硬闯护栏），不能无限跑
3. 每个"自作主张"必须**留痕**，事后能查（且要中文可读）

## 三、三级挂机

| 级别 | 行为 | 适用 |
|:---|:---|:---|
| `supervised` **有人盯**（默认） | 需审批就问你，不自作主张 | 交互开发 |
| `semi` **半挂机** | 只对**高风险**（受保护路径、禁命令）出声，其余自决 | 看着点但不想被烦 |
| `unattended` **全挂机** | 完全不打扰：读放行、普通写入自决放行、危险操作静默跳过并记录 | 长程任务、夜间跑 |

### `unattended` 的自决规则（关键）

| 情形 | 决定 | 理由（回灌给模型） |
|:---|:---|:---|
| 只读 | 放行 | — |
| 写工作区内非保护路径 | **放行**（记审计） | 挂机模式：工作区内普通操作，自决放行 |
| 写受保护路径（`.git`、密钥、token 文件） | **跳过** | 目标路径受保护…请换个不触碰该路径的做法 |
| 执行被策略**禁止**的命令 | **跳过** | 命令被策略禁止…请改用安全等价做法 |
| 执行被策略标记**需审批**的命令 | **跳过** | 该命令需要人工审批，**无人可批**，已跳过 |

> 最后一条是最重要的取舍：挂机时"需要审批的命令"**绝不默认放行**。
> 放行等于把"人工确认"这道闸门在无人时悄悄打开，那是安全事故的典型形态。

### 停止条件（护栏）

`AutonomyEngine.check_stop()` 在**每轮迭代开始前**检查（`engine_loop` 内接线）：

| 条件 | 默认阈值 | 停止理由（中文） |
|:---|:---|:---|
| 连续跳过 | 5 次 | 模型在硬闯安全护栏，继续执行不会有好结果 |
| 迭代数 | 40 步 | 已达步数上限，先停下交付阶段性成果 |
| 连续失败 | 5 次 | 再试大概率还是失败，建议先排查根因 |
| 成本 | $5 | 达到预算上限 |
| 时长 | 120 分钟 | 达到时长上限 |

护栏自身异常只记警告、不阻断任务（护栏不能成为新的故障点）。

## 四、接线

- `ToolManager(..., autonomy=engine)`：`ASK` 分支先问自决引擎，
  `PROCEED` → 记入会话授权并放行；`SKIP/ABORT` → 抛 `ToolApprovalDeniedError`（理由回灌模型）
- `AgentEngine` 按 `CLAWD_AUTONOMY` 环境变量构造引擎；未设置 = `supervised` = 行为与以前完全一致
- CLI：`clawd run --autonomy unattended|semi|supervised`（无效值 exit 2 并列出可选值）
- 审计：`.clawd/autonomy/decisions.jsonl`，字段全中文（时间/挂机级别/工具/决策/理由）

## 验证

- `tests/agent/test_autonomy.py` **23 passed**：三级行为、受保护路径跳过、禁命令跳过、
  **需审批命令绝不自动放行**、连续跳过/迭代/失败/成本护栏、中文审计字段、中文小结、
  ToolManager 集成（unattended 放行普通写、跳过保护路径、supervised 保持旧行为）、
  `clawd permissions` 中文输出与 `--rules` 明细
- `tests/agent/` 全量 **658 passed**（既有审批契约无回归）

## 边界

- `semi` 的"高风险"判定复用受保护路径 + 禁命令两类，**未按工具类别细分**（如删库类 SQL、大额转账）
- 自决不涉及"多方案取舍"（那是模型的活），只做**权限层面的放行/跳过/中止**
- 挂机期间的人工介入：目前只能中断进程；未做"运行中插入确认"的通道
- 预算护栏依赖 `session.total_cost` 有值；无成本统计的路径上该项不生效（其余护栏照常）

## 五、真实 E2E 抓到的三个问题（都已修）

用 `CLAWD_AUTONOMY=unattended` 真跑一次"写文件"任务，暴露了三件事：

### 1. 策略"允许"的命令被误跳过（设计缺陷）
现象：`ls -la .` 在挂机时被跳过，理由却是"需要人工审批"。
根因：`PermissionEngine` 对 exec 的 `ALLOW` 判决只体现在"不禁止"，
下游拿到的仍是 `ASK`，**分不清"策略明确允许"与"策略要求审批"**——两者天差地别。
修复：`Decision` 新增 `policy` 字段（allow/prompt/forbidden），
挂机自决据此判断：`policy == "allow"` → 放行；`prompt`/空 → 跳过。

### 2. 模型不知道能用什么命令，白烧迭代
现象：模型反复尝试 `pwd; ls -la`、`find ... | head -50` 这类复合/管道命令，全被跳过。
根因：挂机时我们保守跳过一切复合命令（正确，因为 `;`/`|` 可以藏危险操作），
但**没告诉模型可用清单**。
修复：`AutonomyEngine.allowed_command_hint()` 生成中文清单，引擎在挂机时注入系统提示；
同时扩充只读安全清单（`find/head/tail/wc/tree/du/which/date/mkdir`、`git branch/rev-parse`）。

### 3. `.clawd/` 目录被文件工具自身拒绝（既有保护，非缺陷）
现象：E2E 想写 `.clawd/_auto_demo/hello.txt`，自主决策放行了，但工具报"路径安全检查拒绝"。
结论：这是**工具层的既有保护**（`.clawd` 存运行时状态），合理，不改。
但要在文档里写清：挂机也无法通过工具改 `.clawd/` 内部文件。

### 挂机写盘路径已确定性验证
不经 LLM 直接验证完整链路：
```
ToolManager(autonomy=全挂机) → FileEditTool 写 demo_out/hello.txt
→ success=True，文件内容正确，审计留痕：
{"工具":"FileEditTool","决策":"放行","理由":"挂机模式：工作区内普通操作，自决放行"}
```
